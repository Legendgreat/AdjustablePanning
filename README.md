Adjustable Panning for the 2D Editor lets you set your mouse's side buttons to pan.

The 3D Editor already has this functionality built-in to Godot, but for some reason it is missing for the 2D Editor.

*For people who hate using Middle Mouse Button to pan, and people who prefer using Mouse 4 or Mouse 5 to pan or orbit.*

## How to use:

Install the add-on, and under `Project -> Tools -> Adjustable Panning`, select `Open Config...`. 

Set your preferred buttons, and then you simply hold and drag to pan in the 2D Editor.
