# Adjustable Panning

A Godot editor plugin that lets you use Mouse Button 4 and/or Mouse Button 5
to pan the 2D editor viewport.

## Features

- Use Mouse Button 4 and/or 5 for 2D editor panning.
- Uses Godot's native middle-mouse panning behavior.
- No runtime dependencies.

## Configuration

After enabling the plugin, open:

`Project > Tools > Adjustable Panning > Open Config...`

Select which mouse buttons should be used for panning.

## Requirements

- Godot 4.5 or later
